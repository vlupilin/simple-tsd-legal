Политика конфиденциальности Simple TSD

Настоящая Политика конфиденциальности описывает, как FORDEV («мы», «наш», «нас») собирает, использует и защищает информацию пользователей мобильного приложения Simple TSD («Приложение»).

1. Общая информация

Simple TSD — мобильное приложение для автоматизации складских операций, включая сканирование штрихкодов, сборку заказов, инвентаризацию и учёт товаров. Приложение предназначено для использования сотрудниками организаций, подключённых к системе Simple.

2. Какие данные мы собираем

2.1. Данные, предоставляемые пользователем

  • Учётные данные: логин и пароль для авторизации в системе организации
  • Настройки устройства: выбранный язык, тема оформления, настройки сервера

2.2. Данные, собираемые автоматически

  • Идентификатор устройства: уникальный идентификатор для привязки устройства к учётной записи
  • Имя устройства: модель устройства для отображения в системе
  • Информация об устройстве: операционная система, версия приложения
  • Push-токен (FCM/APNs): для отправки push-уведомлений о заданиях и операциях
  • Данные Bluetooth: для подключения принтеров этикеток (идентификаторы устройств)

2.3. Данные, создаваемые при использовании

  • Результаты сканирования: штрихкоды товаров, количество, результаты операций
  • Статусы заданий и операций: информация о выполнении складских задач
  • Фотографии: прилагаемые к результатам операций (если применимо)

3. Как мы используем данные

  • Авторизации пользователей и управления доступом
  • Выполнения складских операций (сканирование, сборка, инвентаризация)
  • Отправки push-уведомлений о новых заданиях и операциях
  • Синхронизации данных между устройством и сервером организации
  • Подключения периферийных устройств (Bluetooth-принтеры)
  • Улучшения работы приложения

4. Хранение данных

4.1. На устройстве

  • Учётные данные хранятся в защищённом хранилище устройства (Keystore/Keychain)
  • Кэш данных товаров и заданий хранится в локальной базе данных
  • Все локальные данные удаляются при выходе из учётной записи

4.2. На сервере

  • Данные хранятся на серверах организации, использующей систему Simple
  • Данные передаются по зашифрованному каналу (HTTPS/TLS)

5. Передача данных третьим лицам

Мы не передаём персональные данные пользователей третьим лицам, за исключением:

  • Firebase Cloud Messaging (Google/Apple) — для доставки push-уведомлений
  • Требований законодательства Республики Казахстан

7. Безопасность данных

  • Все данные передаются по зашифрованному каналу (TLS 1.2+)
  • Учётные данные хранятся в защищённом хранилище устройства
  • Токены авторизации имеют ограниченный срок действия
  • Доступ к данным ограничен рамками организации пользователя

8. Права пользователя

Вы имеете право:

  • Отказаться от предоставления разрешений (камера, Bluetooth, уведомления)
  • Удалить все локальные данные, выйдя из учётной записи
  • Запросить удаление своих данных у администратора организации или через форму запроса удаления

9. Дети

Приложение не предназначено для лиц младше 18 лет. Мы не собираем данные детей намеренно.

10. Изменения политики

Мы можем обновлять данную Политику конфиденциальности. Уведомление о существенных изменениях будет направлено через приложение или по электронной почте.
