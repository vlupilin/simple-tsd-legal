Privacy Policy — Simple TSD

This Privacy Policy describes how FORDEV ("we", "our", "us") collects, uses, and protects user information in the Simple TSD mobile application ("Application").

1. Overview

Simple TSD is a mobile application for automating warehouse operations, including barcode scanning, order picking, inventory, and goods accounting. The application is intended for use by employees of organizations connected to the Simple system.

2. Data We Collect

2.1. User-provided data

  • Credentials: username and password for organization authorization
  • Device settings: selected language, theme, server configuration

2.2. Automatically collected data

  • Device identifier: unique ID linking device to account
  • Device name: device model for system display
  • Device information: operating system, application version
  • Push token (FCM/APNs): for push notifications about tasks
  • Bluetooth data: for connecting label printers (device identifiers)

2.3. Usage-generated data

  • Scan results: product barcodes, quantities, operation results
  • Task and operation statuses: warehouse task completion info
  • Photos: attached to operation results (when applicable)

3. How We Use Data

  • User authorization and access management
  • Execution of warehouse operations (scanning, picking, inventory)
  • Sending push notifications about new tasks
  • Syncing data between device and organization server
  • Connecting peripheral devices (Bluetooth printers)
  • Improving application performance

4. Data Storage

4.1. On-device

  • Credentials are stored in device secure storage (Keystore/Keychain)
  • Goods and task data cache is stored in local database
  • All local data is deleted upon logout

4.2. On-server

  • Data is stored on the servers of the organization using Simple
  • Data is transmitted over encrypted channel (HTTPS/TLS)

5. Third-party Sharing

We do not share user personal data with third parties, except:

  • Firebase Cloud Messaging (Google/Apple) — for push notification delivery
  • Legal requirements of the Republic of Kazakhstan

7. Data Security

  • All data is transmitted over encrypted channel (TLS 1.2+)
  • Credentials are stored in device secure storage
  • Authorization tokens have limited lifetime
  • Data access is scoped to the user's organization

8. User Rights

You have the right to:

  • Refuse permissions (camera, Bluetooth, notifications)
  • Delete all local data by logging out
  • Request deletion of your data via the organization administrator or data deletion request

9. Children

The application is not intended for users under 18. We do not knowingly collect children's data.

10. Policy Changes

We may update this Privacy Policy. Notice of material changes will be sent via the application or by email.
